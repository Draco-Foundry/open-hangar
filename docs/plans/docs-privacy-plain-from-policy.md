# docs/privacy-plain-from-policy

## Goal

`docs/store-assets/privacy-plain.txt` (the privacy policy as plain text, for store
forms) is out of date: it still says there's no server and has no Add to RSI Cart
section. Owner-approved (2026-10-13): replace it with `docs/PRIVACY.md`, word for word,
as plain text, with a test that fails the build if the two drift. No new words.

## Steps

1. `scripts/privacy-plain.mjs` (`npm run privacy:plain`): turns `docs/PRIVACY.md` into
   plain text and writes the file. Only Markdown goes: heading marks (section headings
   in capitals, as the file does today), bold and italic marks, code marks, and link
   syntax (the link's text, then its address in parentheses when the text isn't the
   address). List items keep "- ". Markdown it doesn't know fails loudly.
2. Run it and commit the new `privacy-plain.txt`.
3. `test/privacy-plain.test.js` in `npm test`: regenerates the text and fails, saying
   how to regenerate, when it differs from the committed file; checks the words match
   the policy's, in order.
4. One line in `docs/STORE.md` (store assets): the file is generated, and how.
5. `npm run format:check` and `npm test` green.

## Done When

- `privacy-plain.txt` is `docs/PRIVACY.md` as plain text, regenerated by the script.
- `npm test` fails while the two differ.
- The checks pass, and this plan is deleted before the PR is ready.
