# 0.3.0: The Redesign

The 0.3.0 redesign is built. Its signed-off specs (the Clean Pro style, the Home layout,
the Top Bar, the Top Menu Pass, Inventory and Buy-Backs, the Filters Pass and the
owner's fix list) were the owner's design notes and are kept in the maintainer's
private notes. The code is now the reference: `ui/tokens.css` for the look, and each
page under `ui/`.
