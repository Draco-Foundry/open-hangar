# Security Policy

Found a security problem in Open Hangar? Thank you for looking. Please tell us
privately so we can fix it before anyone else can use it.

## How to Report

- **Preferred:** GitHub's private reporting. Go to the
  [Security tab](https://github.com/Draco-Foundry/open-hangar/security) and choose
  **Report a vulnerability**. Only the maintainers can see it.
- **Or email** [support@openhangar.space](mailto:support@openhangar.space) with
  "Security" in the subject.

Please **don't open a public issue, Discord post or pull request** for a security bug.
Those are visible to everyone until the fix ships.

A good report says what's affected, how to reproduce it, and what someone could do with
it. Screenshots or a short video help. Never include your RSI password, session cookies
or anyone's personal data.

## What's in Scope

- The Open Hangar browser extension (Chrome, Edge, Firefox), including its handling of
  your RSI session and the data it saves on your computer.
- [openhangar.space](https://openhangar.space/), including its status file.
- [app.openhangar.space](https://app.openhangar.space/), the account and sync site
  (invite-only for now).

Not in scope: RSI's own website and services (report those to
[Cloud Imperium](https://robertsspaceindustries.com/), not to us), and reports that
need someone's unlocked computer or an already-compromised browser.

## What to Expect

- We aim to reply within **3 days** to say we got it.
- We'll keep you posted while we work on it, and tell you when the fix is out.
- Fixes for serious problems ship as soon as the browser stores approve them; we can
  also pause an affected feature remotely in the meantime.
- If you'd like credit, we'll thank you by name in the release notes once it's fixed.

Open Hangar is a small fan project with no bug bounty, but every report is read and
appreciated.
